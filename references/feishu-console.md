# 飞书开发者后台配置

后台地址：https://open.feishu.cn/app 。分两段做：第一段建应用、开权限（不需要飞书桥在跑）；第二段配事件、回调、菜单、发布（**需要飞书桥已经用这个应用连上长连接**，否则长连接存不进去）。

## 第一段：建应用

1. **创建企业自建应用**（列表页上方的按钮）。名称随用户喜欢，比如「飞书桥」「我的电脑」；描述写用途；图标用默认的就行。点「创建」后进入应用页，地址里的 `cli_…` 就是 App ID。
   - 不要用页面顶部那个「创建飞书智能体应用」，也不要用妙搭「部署 OpenClaw」、Aily 建的应用：那些应用的底部菜单由平台管理，开发者后台配置不生效（飞书文档原话：「该悬浮菜单由智能伙伴搭建平台管理，开发者后台的配置默认不生效」）。
2. **添加应用能力 → 机器人 → 添加**。
3. **权限管理 → 开通权限**，在搜索框里按权限码搜，逐个勾上（勾选跨搜索保留，底部显示「已选 N 项」），最后点「确认开通权限」。四项都是「免审权限」：

   | 权限码 | 用途 |
   |---|---|
   | `im:message.p2p_msg:readonly` | 收用户发给机器人的单聊消息 |
   | `im:message:send_as_bot` | 以应用身份发消息、发卡片、改卡片 |
   | `im:resource` | 上传图片和文件（结果附件、截图） |
   | `im:message:readonly` | 下载用户发来的图片和文件（漏了它，手机发图片会失败） |

4. **凭证与基础信息**：App ID 抄给 `config.toml`；App Secret 让用户自己点复制图标，粘进 `setup_secrets.py`（见 SKILL.md 第 3 步）。

做完这段，回到 SKILL.md 做第 3～5 步（存密钥、登录、让飞书桥连上）。

## 第二段：事件、回调、菜单、发布

### 事件配置

「事件与回调 → 事件配置」：

1. 「订阅方式」旁的编辑图标 → 选「使用 **长连接** 接收事件」→ 点「验证」，要显示「连接成功」→「保存」。验证失败就是飞书桥没连上：看 `data\bridge.log` 有没有 `connected to wss://`。
2. 「添加事件」→ 搜 `im.message.receive_v1`（接收消息）→ 勾选 →「添加」。列表里应显示所需权限「读取用户发给机器人的单聊消息 · 已开通」。

### 回调配置

同一页切到「回调配置」标签（**在另一个标签页里，很容易漏**）：

1. 订阅方式同样改成长连接 →「验证」→「保存」。
2. 「添加回调」→ 勾「卡片回传交互 `card.action.trigger`」（不是下面那个「旧版」）→「添加」。漏了这一步，审批卡上的按钮能看到但点了没反应。

### 底部菜单（推荐配）

「机器人 → 机器人自定义菜单」旁的编辑图标：

1. 菜单状态：**开启**（新应用默认是关的）。
2. 展示形式：**可切换菜单**（菜单占最底下一栏，左边键盘图标切回输入框）；默认展示：**菜单**。另一种「悬浮菜单」是浮在输入框上方，也能用。
3. 菜单项（响应动作全部选 **「发送文字消息」**）：

   - 主菜单「会话」，下面 4 个子菜单：`会话列表`、`最新记录`、`电脑上打开`、`新会话`
   - 主菜单「切换会话」

   建子菜单：先填主菜单名，点预览里的「+ 新建子菜单」，弹窗点「新建并转移」——主菜单原来填的内容会挪到第一个子菜单上，要把主菜单名再填一遍，把子菜单名改成 `会话列表`。之后每点一次「+ 新建子菜单」加一个。再点预览里的「+」或「添加菜单」加第二个主菜单。
4. 「保存」。

**为什么名字要一字不差**：「发送文字消息」的效果是以用户的身份把菜单名原样发给机器人（聊天里会看到他「说」了一句「切换会话」）。飞书桥只认整句、而且只认这几个词（`fb/policy.py` 的 `MENU_WORDS`），名字改了它就会当成普通任务交给 Claude。想改名，要同时改 `MENU_WORDS`。

如果名称栏上方有「简体中文 / 英语 / 日语」标签（应用配了多语言），三种都必填，不填保存会报「请至少填写 2 个字符」。飞书桥认这些英文和日文名：

| 中文 | 英语 | 日语 |
|---|---|---|
| 会话列表 | Session list | セッション一覧 |
| 最新记录 | Latest | 最新記録 |
| 电脑上打开 | Open on PC | PCで開く |
| 新会话 | New session | 新規セッション |
| 切换会话 | Switch session | セッション切替 |

主菜单「会话」只负责弹出下拉，英日文随便填（比如 Sessions / セッション）。

飞书客户端低于 7.22 时，「发送文字消息」类菜单项不显示。

### 创建版本并发布

「版本管理与发布 → 创建版本」：

1. 版本号：页面可能已经预填好（比如 1.0.0），直接用，别在后面再打一遍。
2. 更新说明：写一句就行。
3. 可用范围：「部分成员」，成员里只有用户自己。只有所有者加 10 人以内时，页面顶部会显示「本次发布免审核」。
4. 对外共享：两个勾都不要勾。
5. 「保存」→ 弹窗「确认发布」。版本状态变成「已发布」就生效了。菜单在发布后 5 分钟内生效，手机上退出聊天再进来就能看到。

以后改菜单、改权限都要再发一个版本才生效。只改「展示形式」时页面不一定提示要发版本，保险起见也发一个。

## 删除应用

已启用的应用，「凭证与基础信息 → 更多操作 → 删除应用」是灰的，要企业管理员先在管理后台「停用」它。普通员工自己删不了。
