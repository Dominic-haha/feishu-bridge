# 手机上怎么用飞书桥

在手机飞书里打开你的机器人（装的时候起的名字），就像和人聊天一样给它发消息。

## 派活

- **直接发一句话** = 派一个新任务，电脑上的 Claude 开一个新会话去做。先回一张状态卡，执行中会更新进度；做完单独发一张结果卡（手机会响）。结果太长会附一个 `.md` 文件。
- **引用回复某张结果卡** = 在同一个会话里接着聊。
- **发图片或文件**：先存到电脑上工作目录下的 `_飞书收件/日期/` 里，回你「📎 收到」；你接着发的那句话会带上这些附件一起交给 Claude。2 分钟没下文，就直接让 Claude 看看是什么。
- 一次只跑一个任务，再发的会排队。

## 审批

Claude 要做需要授权的事（写文件、跑命令……）时，会发一张审批卡：

- 「允许」：只放行这一个操作。
- 「本任务都允许」：这个任务后面的操作都放行，任务结束就失效。
- 「拒绝」：不让做，Claude 会换个办法或停下来说明。
- 5 分钟不点，按拒绝处理。

## 底部菜单

| 菜单 | 作用 |
|---|---|
| 会话 ▸ 会话列表 | 列出电脑上最近 10 个会话（桌面版侧边栏里的 + 手机上开的） |
| 会话 ▸ 最新记录 | 看当前接上的会话最近几轮对话（电脑上刚聊的也能看到） |
| 会话 ▸ 电脑上打开 | 在电脑的 Claude 桌面版里打开当前接上的会话；没接上就打开最近一个手机上跑的 |
| 会话 ▸ 新会话 | 不接着了，之后每条消息各开一个新会话。点它本身不建会话，发下一条消息才建；电脑桌面版侧边栏里要等这条跑完、在电脑上打开后才有（开了自动同步会自己打开） |
| 切换会话 | 弹出会话列表，点「接着聊」就切过去 |

点菜单时，聊天里会显示你「说」了一句菜单名，这是正常的。

## 接着电脑上的会话聊

1. 点「切换会话」，在列表里点某个会话的「接着聊」。飞书桥会先推最近几轮对话给你看。
2. 之后你直接发的消息都接着那个会话聊，在它原来的目录里跑。
3. 不想接着了，点「会话 ▸ 新会话」。

两点注意：

- **别在手机和电脑上同时对同一个会话说话**。飞书桥发现这个会话在电脑上正开着、或者刚有动静时，会先弹确认卡。开了「自动同步到电脑」的话，手机新开的会话跑完就在电脑上开着了，再接着聊也会先确认。
- **很长的会话接着聊很费额度**（每次都要带上全部上下文）。会话记录超过 3 MB 时会先弹确认卡，写明大小，想清楚再点「执行」。

手机上接着聊的内容会写进同一份会话记录，电脑上重新打开那个会话就能看到；不是实时刷新的。

## 指令（不用菜单时手打）

| 指令 | 作用 |
|---|---|
| `/状态` | 看正在跑的、排队的、等确认的、最近完成的任务 |
| `/停止` | 停掉正在跑的任务（状态卡上的「停止」按钮也行） |
| `/急停` | 停掉当前任务、清空队列，之后的消息都不执行 |
| `/恢复` | 解除急停 |
| `/会话`、`/记录`、`/电脑打开`、`/新会话` | 同底部菜单 |
| `/帮助` | 看用法 |

## 会先确认、不自动执行的情况

- 消息发出超过 10 分钟才被收到（多半是电脑离线时积压的）。
- 60 秒内发了一模一样的内容。
- 要接着的会话在电脑上正开着、刚有动静，或者记录很大。

## 电脑要开着

电脑关机或睡着就收不到消息，醒来后积压的消息会先弹确认卡。Windows：插电时在电源设置里把「睡眠」改成「从不」。Mac：「系统设置 → 电池 → 选项」里打开「接电源时防止自动睡眠」，合上盖子通常还是会睡。
